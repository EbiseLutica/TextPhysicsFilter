AviUtl2 のテキストオブジェクトに直接追加して使う、テキスト専用の物理演算フィルタです。
物理ワールド全体のプラグインを完成させる前にテキスト機能だけを配布できるよう、独立した新規フォルダへ必要な実装をコピーして構成しています。元の `physics_world_plugin` から機能を削除・移動してはいません。

## 使い方

1. AviUtl2 でテキストオブジェクトを作成します。
2. そのオブジェクトへ「テキスト分解物理」フィルタを追加します。
3. 「分割単位」で「1文字ずつ」または「文字内のαパーツ」を選びます。

「1文字ずつ」は離れた画素を同じ文字としてまとめます。「文字内のαパーツ」は、α値から判定した連結パーツごとに分解します。漢字などの細いアンチエイリアスが別パーツ同士を誤結合しにくい判定を使用しています。

初期状態では反発を無効にし、「倒れやすくする」を有効にしています。画面端との衝突が不要な場合は「画面端と衝突」をOFFにしてください。

## パラメータ

| パラメータ | 初期値 | 設定範囲 | 説明 |
| --- | ---: | ---: | --- |
| 静的オブジェクトにする | OFF | ON / OFF | ONにしたテキストは物理演算せず、そのまま表示されます。同じシーンの別レイヤーにある、このフィルタを付けた他のテキストが、このテキストの文字形状を動かない地形として衝突します（実験機能）。 |
| 衝突グループ | 0 | 0～99 | `0`は他のテキストと衝突しません。同じ番号を付けた複数のテキスト（別レイヤー）は、互いに衝突します（実験機能）。 |
| 分割単位 | 1文字ずつ | 1文字ずつ / 文字内のαパーツ | 物理ボディを作る単位を選びます。「1文字ずつ」は同じ文字に属する離れた画素をまとめ、「文字内のαパーツ」はα値から検出した連結パーツをそれぞれ独立した物体にします。 |
| αしきい値 | 1 | 1～255 | 分解対象として扱う画素の最低α値です。値を上げるほど半透明部分を無視します。細い装飾が消える場合は下げ、半透明の縁を拾いすぎる場合は上げてください。 |
| 重力 | 1800 | -100000～100000 px/s² | ワールド全体の下向き加速度です。`0`で無重力、負の値で上向きに重力が働きます。 |
| 重力倍率 | 1.00 | -10.00～10.00 | このテキストに適用する重力の倍率です。`0`で重力の影響を受けず、負の値で重力方向が反転します。 |
| 摩擦 | 0.50 | 0.00～1.00 | 画面端や他の文字パーツと接触したときの滑りにくさです。`0`に近いほど滑り、`1`に近いほど止まりやすくなります。 |
| 反発 | 0.00 | 0.00～1.00 | 接触時の跳ね返りの強さです。`0`ではほぼ跳ねず、値を上げるほど強くバウンドします。 |
| 密度 | 1.00 | 0.01～1000.00 | 文字パーツの質量を決める密度です。同じ大きさなら値が大きいほど重くなり、パーツ同士が衝突した際の動きや回転の変化に影響します。重力による落下加速度そのものは変わりません。 |
| 初速の強さ | 0 | 0～8000 px/s | 再生開始時に各パーツへ与える移動速度です。`0`ではその場から動き始めます。 |
| 初速角度 (-360～360) | 0° | -360°～360° | 初速を与える方向です。`0°`は上、`90°`は右、`180°`は下、`-90°`は左です。「初速の強さ」が`0`の場合は動きに影響しません。 |
| 回転速度 | 0°/s | -2000～2000°/s | 再生開始時に与える回転速度です。正負で回転方向が変わります。`0`でも「倒れやすくする」がONなら、パーツごとに小さな回転が自動で加わります。 |
| 倒れやすくする | ON | ON / OFF | ONでは各パーツに少しずつ異なる初期傾きと回転を与え、文字が平行なまま落ちにくくします。OFFかつ回転速度が`0`の場合は回転を固定します。 |
| 画面端と衝突 | ON | ON / OFF | ONでは画面の上下左右を固定された壁として扱います。OFFではパーツが画面外へそのまま移動します。 |
| 計算精度 | 4 | 1～16 | 1フレーム内の物理計算回数です。値を上げると高速移動時のすり抜けや接触の不安定さを抑えやすくなりますが、処理負荷も増えます。 |
| 停止速度 | 15 | 0～500 px/s | パーツをスリープさせる速度の目安です。値を上げるほど早く静止し、下げるほど小さな動きが長く残ります。 |

### 衝突グループについて

- 同じ番号のテキストはすべて、このフィルタを付けて同じ番号にしてください。「静的オブジェクトにする」がONのテキストは地形になり、番号に関係なく全員が衝突します。
- 重力・計算精度・画面端・領域は、グループ内で最も小さいレイヤーのテキストの設定が全員に使われます。摩擦・反発・密度・初速・回転などは、各テキストの設定がそのテキスト自身に使われます。
- 開始フレームはずらせます。各テキストは自分の開始フレームから現れます。
- 衝突に使う文字の形は、フィルタを適用する前のテキスト画像から作ります。このフィルタより前に別のエフェクトを付けている場合、形がずれることがあります。
- 終了したテキストは、そのフレーム以降は計算に含まれません。衝突させたいテキストは、同じ区間に置くのが安全です。

パラメータを変更すると、そのフレームの表示だけを途中から変更するのではなく、開始時点から物理演算を再計算します。そのため、長いテキストや「文字内のαパーツ」を使用している場合は、変更直後の表示に時間がかかることがあります。
